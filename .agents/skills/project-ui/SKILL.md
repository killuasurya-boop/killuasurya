description: Repair KILLUASURYA.TECH React interfaces, accessibility, themes, motion and responsive behavior while preserving brand assets.
---

- Inspect the existing route and relevant committed screenshots before editing. Refinements retain the approved Electric Doodle identity, Indonesian copy and real product behavior.
- Use semantic buttons/links, associated labels, meaningful errors, visible keyboard focus, dialog focus handling and sufficient contrast in both themes. Preserve reduced-motion alternatives and access to revealed content.
- Forms need pending, disabled, success and retry states. Stop duplicate submissions; preserve entered data on errors. Ensure prop spreading cannot override a computed disabled state.
- Validate at desktop and narrow mobile widths. Long text, empty results and zero-valued charts must not produce overflow or invalid SVG values.
- Follow React hook rules; parallelize independent reads and deduplicate repeated server identity lookups per request, never with shared mutable cross-user state.
- Use bounded visual inspection: desktop/mobile together, one batch of fixes, then confirmation. Do not replace original brand assets or invent customer claims.

Source guidance: Impeccable audit/harden and Vercel React best practices. For a new visual direction, load the appropriate design skill rather than treating this maintenance guide as a redesign brief.
